1. 概览与入门步骤

Gin-Factory 是装在口袋里的个人金酒吧：您可以管理库存、存放位置、心愿单、配方和统计数据。一切都在您的设备上运行；借助同步码，可以连接多台设备。

在底部（PC 和横屏 iPad 上：在左侧）有一个包含八个区域的栏：

区域用途
酒吧所有金酒（以及汤力水）、搜索、筛选、排序、添加金酒、饮用
统计库存、价格、存放、饮用历史的分析
配方13 款金汤力与鸡尾酒经典、自己的配方、香草与装饰架
历史您已喝过的金酒
酒架存放规划：存放和移动金酒、二维码标签
心愿单您还想购买的金酒
导入导出备份您的数据，读入表格和备份文件
设置名称、货币、语言、云端、定义酒架

最初的五个步骤

  1. 选择语言和货币：设置 → 通用。货币会自动跟随语言。
  2. 定义酒架（可选）：设置 → 酒架（参见第 5 节）。
  3. 添加您的第一款金酒：在酒吧中点按 +（第 2 节）。
  4. 存放它：为这款金酒指定酒架中的一个位置。
  5. 备份：导入导出 → JSON 备份，或设置云端同步（第 13 节）。
设置中的各部分可以折叠。首次启动时“通用”是展开的，其余为折叠状态。应用会记住您上次展开或折叠的内容。

2. 添加金酒

在酒吧中点按 +。添加金酒有多种方式，可以组合使用。

a) 手动输入

填写各字段：名称 / 酒厂、装瓶年份、瓶数、金酒风格、产区、国家、植物原料、ABV (% vol.)、搭配的汤力水、完美饮法、存放位置（酒架 · 层 · 从左数第几位）、价格、酒瓶图片（网络链接）、自己的照片、评分、备注。只有名称是必填项。点按保存即可创建这款金酒。

  • 金酒风格：London Dry、Old Tom / Plymouth、粉红 / 水果金酒、Navy Strength、汤力水或其他。
  • 装瓶年份是该酒瓶的装瓶年份；植物原料是酿造所用的植物（例如杜松子、芫荽籽、柑橘皮）；ABV (% vol.) 是酒精度。
  • 库存、最低和最高：如果您输入了最低值，库存低于该值时应用会发出提醒，并建议将这款金酒加入心愿单（第 3 节）。
  • 自己的照片：“拍照 / 选择照片”可为金酒附上一张照片。照片保存在此设备上，包含在 JSON 备份中，但不会同步到云端。
  • 搭配的汤力水与完美饮法：参见第 8 节。

b) 扫描酒标（AI）

点按扫描酒标（AI）并拍摄酒瓶的酒标。AI 会读取名称、年份、风格、产区、国家、植物原料和 ABV。请检查这些值后再保存。首次使用前，应用会征求您的同意（第 14 节）。

c) 扫描条形码

点按扫描条形码，将酒瓶的条形码对准取景框。应用会在免费的商品数据库中查询该编号（免费，不消耗 AI 额度），如果找到，就会填入名称、生产商和金酒风格。装瓶年份是可选的，应用会向您询问。

  • 如果这瓶酒已经在酒吧中，应用会询问“再添加一瓶吗？”——当您又买了同样的酒时，这是增加数量的快捷方式。
  • 如果条形码不在数据库中（小型酒厂很常见），会出现带有扫描酒标（AI）按钮的提示。该编号仍会与金酒一起保存，这样下次就能立即识别这瓶酒。

d) 查询金酒（AI）

查询金酒（AI）会让 AI 在网上搜索产区、国家、植物原料、ABV、当前平均价格，以及（在网页版中）酒瓶图片。您已填写的字段不会被覆盖。输入名称和年份且尚无价格时，这也会自动执行。

iPhone 应用不会从互联网加载酒瓶图片（App Store 规定）。您可以改为拍摄自己的照片。

e) 添加汤力水

汤力水的添加方式与金酒完全相同：在风格中选择汤力水（🥤）即可。筛选中也会出现单独的“汤力水”项。汤力水卡片上会以适合搭配：…显示与之相配的金酒。

3. 酒吧

搜索、筛选、排序

  • 顶部的搜索：按名称、产区、国家和酒厂查找金酒。
  • 筛选：全部、London Dry、Old Tom / Plymouth、粉红 / 水果金酒、Navy Strength、汤力水、其他。点按某个风格时，搜索内容会自动清除。
  • 排序：最新添加、名称、装瓶年份、植物原料、产区或国家。
  • 列表 / 卡片：列表按钮可在紧凑列表和详细卡片之间切换。

金酒卡片

卡片显示名称、装瓶年份、酒厂、评分（星级）、产区和国家（点按可打开地图或该国的金酒产区地图）、瓶数、植物原料以及存放位置（点按可跳转到酒架）。每张卡片上的杜松子用颜色表示金酒的风格；点按浆果即可打开该金酒的维基百科页面（参见“浆果颜色代表什么？”）。

卡片底部有：编辑、饮用和 🗑（删除金酒）。

库存、最低/最高与购物清单

如果您为某款金酒输入最低值（也可选择输入最高值），卡片会显示“库存 · 最低 · 最高”，低于该值时以 ⚠ 提醒。补货按钮会打开购物清单：列出所有低于最低值的金酒（目标为最高值，否则为最低值）。您可以分享或复制该清单，也可以将这些金酒加入心愿单。

4. 饮用金酒

在金酒卡片上点按饮用，会打开喝金酒对话框：

  • 从哪个位置取出？——选择酒瓶取自的酒架位置，或选择“酒瓶不在任何位置”。该位置随即空出。
  • 和谁一起喝的？——您的客人姓名（可选）。
  • 场合——春天、夏天、秋天、冬天、生日、派对或“随心小酌”（可多选）。

饮用会减少一瓶，并在历史中创建一条记录。彩带和音效会为此庆祝（可在设置中关闭）。如果这是最后一瓶，应用会告知您：这款金酒随后会从酒吧中消失（但仍保留在历史中）。

扫描快速饮用：酒吧中的圆形按钮会拍摄酒标，在您的酒吧中识别出这款金酒，并立即打开“饮用”对话框。

4a. 酒瓶、dram 与品鉴笔记

一瓶酒可以喝上许多个夜晚，因此饮用现在会倒出一份，并记录剩余酒量，而不是直接扣除整瓶。

  • 饮用： 点按饮用，选择以 cl 为单位的量（2、4、6、10 或自定义）。应用会从剩余最少的已开瓶中倒酒，或开启一瓶新的未开封酒。确认之前，你会看到之后还剩多少。
  • 瓶子空了： 勾选“这样瓶子就空了”（或把剩下的都倒出来）。只有这时才会从库存中取出一瓶，并询问它来自哪个架位。
  • 移除空瓶: 在卡片上点按 🏁 已空(列表中为 🏁 按钮)。应用会从库存中取出剩余最少的酒瓶(或未开封的),询问酒架位置,并可将剩余部分记为已饮用写入历史。
  • 在卡片上： 🔓 已开瓶的酒显示剩余 cl 和酒量条，🔒 未开封的酒和瓶容量。筛选标签🔓 已开瓶和🔒 未开封可缩小列表范围。
  • 历史： 每一份都是一条记录，带有以 cl 为单位的量；喝空的瓶子标有 🏁。每份的价格按比例计算。

新字段

  • 酒瓶： 容量（cl）和市场价值。
  • 品鉴： 香气、口感、余韵和评分（0–100）。

排序、搜索与统计

  • 可按 ABV 或评分排序。搜索也能找到品鉴笔记。
  • 统计：以 cl 计的容量、已开瓶的酒、已饮用的量和份数、市场价值与购买价格的对比，以及每 cl 的平均价格。
  • CSV 和 Excel 导出包含新列；导入时也能识别它们。

5. 酒架与存放

定义和编辑酒架

设置 → 酒架（点按标题展开）：输入名称、层数、每层位置数和每个位置的瓶数，然后点按 ＋。“瓶/位”对于瓶架为 1，对于地面或木箱则更大。在列表中，每个酒架都有：

  • 用于更改顺序的拖动柄 ⠿，以及列表下方的按 A–Z 排序按钮，
  • ▦ 用于二维码标签，✏️ 用于编辑，🧹 用于清空，🗑 用于删除。

通过编辑（✏️），您可以重命名酒架、更改每层的位置数、在上方或下方添加层、删除层，并为每一层指定独立的名称和瓶数。因此失去位置的酒瓶之后会被视为“未存放”；金酒本身仍保留在酒吧中。进行此类更改前，应用会先询问。

“酒架”区域

在顶部，您通过磁贴（名称和“已占用 / 位置数”）选择酒架。顺序也可以在这里更改：在 PC 上拖动磁贴，在触摸屏上长按磁贴约半秒，然后拖动。下方是存放规划：每一层及其位置。已占用的位置会显示一个颜色与金酒风格对应的酒瓶。

存放

  1. 在“未分配”下点按一款金酒（该列表可按酒厂和国家筛选）——或在酒吧中点按“未存放”提示。
  2. 点按一个空位。对于地面和木箱，应用会存入尽可能多的酒瓶。

扫描并存放金酒会拍摄酒标、找到该金酒，并引导您完成存放。

已占用的位置、移动、移除

点按已占用的位置：您会看到这款金酒，并可以打开它、从位置移除或移动（然后点按一个空位）。清空酒架会取出酒架中的所有酒瓶（需确认）。

二维码标签与“扫描层”

通过二维码标签（设置 → 酒架 → ▦），您可以为酒架创建一张标签，并为每一层各创建一张。可作为 PDF 分享或打印（标签纸 63.5 × 38.1 mm，每页 21 张）并贴上。之后：在酒架区域使用扫描层——您会看到该层上有什么，并可以存放到这里、取出、饮用、移动酒瓶或整层移动。在“添加金酒”表单中，扫描某一层的标签也会填入存放位置。

6. 历史

历史列出您喝过的所有金酒，包括日期、金酒、价值、客人和场合。您可以按金酒风格和场合筛选，并编辑记录（客人、场合）。历史为统计中的饮用、支出和饮用频率分析提供数据。

7. 心愿单

  • + 添加心愿：手动添加或通过扫描酒标添加，可附带可选备注（“在哪里购买？”）。
  • 搜索价格（💶）：应用会在网上搜索这款金酒的价格，显示最便宜的结果并乘以数量。这些是不作保证的参考值——请向店家确认运费和库存情况。
  • 左侧的勾选框：标记为已购买/已完成（该行会变淡）。
  • → 酒吧：将心愿移入酒吧（带数量，如有则带最低价格），如果您有酒架，会直接进入存放流程。
  • 如果某款金酒低于其最低值，应用会建议按缺少的数量将其加入心愿单（“补货”）。
  • 完美饮法中标有购物提示（🛒）的汤力水，以及缺少的香草和装饰，也可以加入心愿单（第 8 节、第 9 节）。

8. 完美饮法与酒杯

在“添加金酒”或“编辑金酒”表单中有一个完美饮法（香草、装饰、比例）区块，告诉您哪种汤力水最适合这款金酒，以及怎样上桌最好。

两种推荐方式

按钮作用
🌿 规则提示在设备上离线运行，免费。根据金酒风格和植物原料（柑橘、草本、花香、香料、浆果等）给出推荐。
🤖 AI 推荐由 AI 针对这款金酒给出推荐，会消耗一次 AI 扫描（第 14 节）。

汤力水推荐

结果最多显示三种汤力水推荐并附理由，例如经典印度汤力水、清淡汤力水（柔和）、地中海汤力水、接骨木花汤力水、姜味 / 香料汤力水、粉红西柚汤力水或柑橘汤力水。每条推荐都会标明：

  • ✓ 酒吧里有：这款汤力水已经在您的酒吧中。
  • 🛒 购物提示：您还没有这款汤力水。用+ 心愿单按钮可以直接把它加入心愿单。

点按一条推荐，即可将该汤力水设为收藏（“已设为收藏 ✓”）。

输入字段

  • 香草和装饰：用逗号分隔（迷迭香枝、百里香、罗勒、黄瓜片、西柚皮、粉红胡椒等）。
  • 比例：例如 1:2。
  • 酒杯：例如 Copa 杯 / 气球杯。
  • 冰块：例如大量大冰块。

搭配的汤力水（🤖）

在表单的搭配的汤力水字段旁点按 🤖，AI 会为这款金酒找到合适的汤力水。若要一次为所有金酒分配，请使用设置 → 分配汤力水（AI）：说明为“为每款尚无汤力水的金酒寻找搭配的汤力水”，应用会先征求确认。它会优先从您已有的汤力水中挑选，否则给出通用推荐。此操作会消耗 AI 扫描。

酒杯信息

酒杯名称是一个链接查看酒杯。点按它会打开一张带插图和简短说明的卡片；卡片下方的查看更多图片 ↗可以找到更多照片，关闭则关闭卡片。有说明的酒杯有：

  • Copa 杯 / 气球杯：金汤力的经典酒杯，宽阔的杯身能释放植物香气。
  • 高球杯：用于汤力水加得多的金汤力和 Tom Collins 等长饮。
  • 平底杯（古典杯）：用于加冰金酒，以及 Negroni、Gimlet 和罗勒 Smash。
  • 浅碟香槟杯（Coupe）：用于 Gimlet、Southside、Bee's Knees 等不加冰的鸡尾酒。
  • 马天尼杯：V 形酒杯，用于干马天尼。
  • 香槟笛形杯：用于 French 75。

金酒卡片上会显示收藏的汤力水、装饰和酒杯。

9. 配方与香草、装饰架

底部栏中的配方区域（副标题“金汤力与鸡尾酒”）收录了 13 款经典，并附有材料和做法：金汤力、地中海金汤力、粉红金汤力、海军强度金汤力、Negroni、干马天尼、Gimlet、Tom Collins、Southside、French 75、Bee's Knees、Martinez 和金酒罗勒 Smash。每个配方还会注明所需的酒杯。

筛选

  • 全部：所有配方。
  • ⭐ 收藏：您用星标标记的配方。
  • 我的：您自己创建的配方，以及您用 AI 生成并保存的配方。
  • ✓ 适合我的酒吧：用您现有的金酒和材料就能做的配方（标有“可做”）。

自己的配方

在添加自己的配方中输入名称、材料（每行一种）和做法，然后点按保存配方。删除这样的配方时需要确认。

金酒配方（AI）

在选择一款金酒…中选择酒吧里的一款金酒，点按🤖 生成配方，AI 就会为它生成配方。喜欢的话，点按保存为我的配方。这会消耗一次 AI 扫描。

我的香草与装饰架

点按您家中已有的香草和装饰（例如青柠角、迷迭香枝、百里香、罗勒、黄瓜片、西柚皮、粉红胡椒）。之后推荐和配方中会显示 ✓（已有）或 🛒（缺少）。点按🛒 将缺少的物品加入心愿单，缺少的材料就会加入心愿单。

配方、收藏和装饰架会随云端同步一并保存（第 13 节）。

10. 统计

从上到下：

  • 关键数据：瓶数、金酒、总价值、平均评分。
  • 按类型（金酒风格）和热门金酒（按评分或饮用频率，可按星级筛选）。
  • 按国家、产区：条形图；点按会在酒吧中搜索。
  • 价格：每瓶平均、最便宜、最贵、价格区间（按您的货币调整）。
  • 储存：占用百分比、空位、未存放的酒瓶，以及每个酒架一条的条形图（点按可跳转到该酒架）。
  • 已喝的金酒和已喝金酒的价值。
  • 补货：低于最低库存的金酒（打开购物清单）、未完成的心愿及其价值。

没有数据的部分（例如没有价格时）会被隐藏。

11. 导出、导入与备份

功能用途
导出 CSV适用于 Excel 或 Numbers 的表格
导出 Excel保存为 .xlsx 文件
导出 PDF可打印的概览
JSON 备份完整数据备份（金酒、心愿单、历史、酒架、显示名称、自己的照片）
复制到剪贴板复制文本清单
导入 JSON / CSV / Excel恢复备份或读入表格

CSV 和 Excel 中包含名称、装瓶年份、风格、产区、国家、植物原料、ABV、酒架、层、位、瓶数、评分、价格、备注等列。导入时也接受旧的列名。

请定期进行 JSON 备份。JSON 导入会用备份内容替换酒吧中的金酒（应用会先询问）。在新设备上，这样可以恢复所有内容。您也可以改用云端同步（第 13 节）。

12. 设置

通用

13. 同步两台设备

  1. 第一台设备：设置 → 存储 → 云端 → 创建新的同步码。同步码会显示在屏幕上；使用通过邮件保存同步码可以发送给自己。
  2. 第二台设备：设置 → 存储 → 云端 → 输入同步码（小写，无空格）→ 连接。如果该设备上已有金酒，应用会询问是否将其与云端数据合并。
  3. 之后两台设备会自动同步（例如打开应用时）；立即同步可手动触发。规则是：以最新的更改为准。

金酒、心愿单、历史、酒架、配方、收藏、香草与装饰架，以及语言、货币等设置都会同步。自己的照片和设备专属数据不会同步。任何知道您的同步码的人都能看到您的金酒——请只与您信任的人分享。同时也请保留一份 JSON 备份。

14. AI、隐私与费用

  • AI 用于什么？扫描酒标、查询金酒、搜索价格、“更新所有金酒”、分配汤力水、AI 推荐（完美饮法）和金酒配方（AI）。照片或金酒名称会通过我们的服务器发送到 AI 服务（Anthropic，美国）进行分析——不含姓名或账户信息。首次使用前，应用会征求您的同意。
  • 扫描条形码只会将编号发送到免费的商品数据库，不消耗 AI 额度。🌿 规则提示同样免费。
  • 费用（iPhone 应用）：每次安装包含 50 次 AI 调用，已含在购买价格中；更多次数可作为可选的一次性购买获得（不是订阅，额度不会过期）。应用中的其他一切功能均无额外费用。额度用完后，除 AI 功能外的所有功能仍可继续使用。
  • 数据：只要您不启用云端，一切都保留在您的设备上。无广告、无追踪、无用户账户。详情请见隐私政策（德语）。

15. 小贴士与常见问题

  • 在 iPad 或 PC 上，布局会自适应：栏更宽、多张卡片并排显示，在 PC（和横屏 iPad）上导航位于左侧。手机也可以横屏使用。在 PC 上，Esc 会关闭最上层的窗口；在手机上，向下滑动窗口即可关闭。
  • 我的金酒不见了：请参见支持——可通过同步码或 JSON 备份恢复。
  • 某款金酒的条形码没有匹配结果：小型酒厂很常见。请使用酒标扫描。
  • AI 读错了：请手动更正字段并保存；AI 给出的值只是建议。
  • 汤力水也可以记录吗？可以。像金酒一样添加，风格选“汤力水”即可。之后完美饮法会用“✓ 酒吧里有”告诉您已拥有，没有的话，则会给出购物提示（🛒），可加入心愿单。
  • 页面仍显示旧版本（网页）：请刷新页面（在 PC 上按 Ctrl+F5）。
